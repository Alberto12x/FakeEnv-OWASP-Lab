# Aplicación web vulnerable para practicar ataques OWASP

Este proyecto consiste en un laboratorio controlado diseñado para la formación práctica en seguridad ofensiva y defensiva. El ecosistema permite la ejecución de vectores de ataque basados en el **OWASP Top 10** y la posterior auditoría de las evidencias generadas en el sistema.

El objetivo principal es proporcionar un entorno de aprendizaje donde se automatice el despliegue de activos vulnerables y la captura de telemetría, permitiendo a diferentes perfiles (Atacante, Analista y Administrador) interactuar con la infraestructura de forma segura y aislada.
